REFERENCE PLACEHOLDERS  (do this ONCE before copying prompts)
-------------------------------------------------------------
Upload your approved picks to Midjourney (or any image host) and copy their
URLs. Then find-and-replace in this file:
  [SANTA_REF]     -> URL of the approved sym_H1_santa   (style + Santa character)
  [KRAMPUS_REF]   -> URL of the approved char_krampus sheet (Krampus character)
  [REINDEER_REF]  -> URL of the approved sym_H3_reindeer   (reindeer character)
Every prompt then carries its references automatically:
  --sref [SANTA_REF] --sw 200   on EVERY image (locks the style)
  --oref [..._REF]  --ow 80–100 on images that show that character
Midjourney v6: use --cref <url> --cw 80 instead of --oref/--ow.
Flux / Leonardo / Firefly: attach the same images as Style Reference
(0.5–0.7) and Character Reference (0.6–0.8) and delete the "--" parameters.
Midjourney v7 allows only ONE --oref per prompt; for images with both Santa
and Krampus (game tile 12.1) generate with [SANTA_REF], then inpaint Krampus
using [KRAMPUS_REF] (Vary Region / Editor).

HOW TO USE THIS FILE
--------------------
1. Every prompt below is SELF-CONTAINED: it already contains the shared STYLE
   block, so you can copy one prompt block (between the ">>>" and "<<<" lines)
   and paste it straight into Midjourney / Flux / Ideogram / Leonardo /
   GPT-Image / Firefly.
2. Always also paste the NEGATIVE PROMPT (section 0.3) into the negative field.
   (Midjourney: add it after "--no", comma separated.)
3. CONSISTENCY RULES — do these in order:
   a) The approved H1 SANTA SYMBOL (section 2.1) is the MASTER REFERENCE.
      Attach it as STYLE reference to every asset (Midjourney: --sref <url>
      --sw 200; others: Style Reference 0.5–0.7). This locks line weight,
      shading, palette and finish.
   b) For anything showing Santa, ALSO attach the Santa symbol as CHARACTER
      reference (Midjourney v7: --oref <url> --ow 100; v6: --cref <url>
      --cw 80; Flux/Leonardo: Character Reference / IP-Adapter at 0.6–0.8). Do NOT use the Santa character
      sheet as a reference: it came out flatter and more generic. The sheet
      is only a pose/expression guide for animators.
   c) For anything showing Krampus, attach the approved Krampus character
      sheet (regenerated with the green coat, section 1.2) as CHARACTER
      reference, plus the Santa symbol as STYLE reference. Anything showing
      a reindeer uses the approved H3 Reindeer as CHARACTER reference.
   d) Re-use the same seed per asset family (all symbols one seed, all
      backgrounds one seed) when your tool supports it.
   e) Never let the AI write text. All words (logo lettering, WIN banners,
      numbers, "WILD") are added afterwards in the engine/Photoshop with the
      game fonts: Lilita One (titles) and Rubik ExtraBold (numbers).
4. Final art pass: an artist paints over every pick (fix hands, eyes,
   symmetry, line weight, cleanup). This is what keeps it from looking
   "AI generated". Check every symbol at 64 px and in greyscale.
5. Symbols / props are generated on flat grey (#808080) and cut out
   (background removal) to transparent PNG.

Suggested tool settings
  Midjourney v7:  --v 7 --style raw --s 150   (references are already in each prompt)
  Flux / SDXL:    CFG 3.5–5, 30–40 steps, same seed per family
  Upscale finals to the "Deliver" size listed for each asset.
